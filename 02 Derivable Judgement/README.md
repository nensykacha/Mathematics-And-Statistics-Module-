# 📊 Derivable Judgement

### Mathematics & Advanced Statistics

## 📌 Project Overview

**Derivable Judgement** is a statistical decision-making project based on health records of individuals from different regions, age groups, genders, and lifestyle categories.

The project applies **inferential statistics and hypothesis testing** to identify significant relationships between lifestyle factors and health conditions such as diabetes and hypertension.

---

## 🎯 Objectives

The main objectives of this project are:

* Understand inferential statistics and hypothesis testing.
* Formulate and test statistical hypotheses.
* Calculate confidence intervals, critical values, and p-values.
* Perform z-test/t-test, chi-square test, and ANOVA.
* Calculate covariance and correlation.
* Interpret statistical test results and make data-based conclusions.

---

## 📊 Dataset

The dataset contains health records with the following fields:

| Field                | Description             |
| -------------------- | ----------------------- |
| `record_id`          | Unique health record ID |
| `age_group`          | Age category            |
| `age`                | Age of individual       |
| `weight`             | Weight of individual    |
| `gender`             | Gender                  |
| `region`             | Geographic region       |
| `smoking_status`     | Smoking habit           |
| `exercise_frequency` | Exercise frequency      |
| `bmi`                | Body Mass Index         |
| `blood_pressure`     | Systolic blood pressure |
| `diabetes`           | Diabetes status         |
| `hypertension`       | Hypertension status     |
| `cholesterol_level`  | Total cholesterol       |
| `glucose_level`      | Fasting glucose         |
| `visit_date`         | Health check-up date    |
