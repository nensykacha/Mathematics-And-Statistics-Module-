# 🎯 Expectation Decider

### Mathematics & Advanced Statistics

## 📌 Project Overview

**Expectation Decider** is a probability analysis project based on a dataset of **200 students**. The project analyzes student study habits, attendance, group discussion participation, and previous test performance to understand probability patterns related to final exam results.

---

## 🎯 Objectives

The main objectives of this project are:

* Understand basic probability concepts.
* Calculate empirical and theoretical probability.
* Create and analyze a random variable and probability distribution.
* Calculate mean and variance.
* Create a Venn diagram using study hours and attendance.
* Create a contingency table.
* Calculate joint, marginal, and conditional probabilities.
* Check whether events are independent or dependent.
* Apply Bayes' Theorem.

---

## 📊 Dataset

The dataset contains **200 student records** with the following fields:

| Field                 | Description                                |
| --------------------- | ------------------------------------------ |
| `study_hours`         | Hours studied per week                     |
| `attendance`          | Lecture attendance percentage              |
| `group_discussion`    | Participation in group discussion (Yes/No) |
| `previous_test_score` | Previous test score out of 100             |
| `final_exam_pass`     | Final exam result (Pass/Fail)              |

## 📚 Topics Covered

### 1. Probability Basics

* Probability definition
* Probability terminology
* Dataset-based probability examples

### 2. Types of Probability

* Empirical Probability
* Theoretical Probability

### 3. Random Variable

The random variable is defined as:

> **X = Number of students passing among 3 randomly selected students.**

The project calculates its probability distribution, mean, and variance.

### 4. Venn Diagram

The Venn diagram represents:

* Students studying more than 10 hours/week
* Students having attendance above 80%
* Students satisfying both conditions

### 5. Contingency Table

A contingency table is created between:

**Group Discussion vs Final Exam Result**

The following are calculated:

* Joint Probability
* Marginal Probability
* Conditional Probability

### 6. Bayes' Theorem

Bayes' Theorem is applied to calculate:

$$
P(Pass \mid High\ Attendance)
$$

using the given historical probabilities.
